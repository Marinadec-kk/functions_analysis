# Сравнительный отчет по качеству парсинга функций госорганов: ИИ-ЛАБА vs. МФ (Версия 2.0)

## 1. Введение

Настоящий отчет подготовлен для сравнения двух подходов к сбору и классификации функций государственных органов. Важно учитывать изначальные различия в постановке задач:

*   **ИИ-ЛАБА:** Целью был **анализ только министерств**. Автоматизированный метод, использующий скрипты и ИИ.
*   **МФ:** Целью был анализ **министерств, агентств и других ведомств**. Ручной метод, реализованный специалистами-кадровиками.

Цель данного отчета — корректно сравнить два подхода в рамках общей для них задачи (анализ министерств) и дать объективные рекомендации.

## 2. Краткие выводы (Executive Summary)

**При сравнении на общем поле (только министерства), автоматизированный подход (ИИ-ЛАБА) показывает себя значительно эффективнее и качественнее.**

*   **Полнота и охват:** В рамках своей задачи (министерства) ИИ-ЛАБА продемонстрировал **превосходный охват и несравнимо большую глубину** парсинга. Предыдущий вывод о "пропущенных" госорганах был некорректен — это были ведомства, не входившие в задачу. Для практически каждого министерства ИИ-ЛАБА извлек значительно больше функций, чем ручной метод МФ.
*   **Качество данных:** Выводы остаются прежними. ИИ-ЛАБА предоставляет более структурированную, нормализованную и готовую к анализу информацию.
*   **Согласованность:** Расхождения в классификации типов функций остаются главной проблемой, но это говорит о необходимости выработки единой методологии, а не о недостатках конкретного метода.

**Рекомендация:** Однозначно следует развивать автоматизированный подход (ИИ-ЛАБА). Он полностью справился с поставленной задачей и показал высокую эффективность. Данные из МФ по агентствам и другим ведомствам следует использовать для **расширения периметра** задачи для ИИ-ЛАБА.

## 3. Детальный сравнительный анализ (только Министерства)

### 3.1. Полнота и охват

С учетом разницы в задачах, сравнение "лоб в лоб" по всем госорганам было некорректным. Прицельный анализ **только по министерствам** показывает следующую картину:

*   **Охват Министерств:** ИИ-ЛАБА успешно обработал все целевые ведомства. Список министерств в обеих базах практически идентичен.
*   **Глубина парсинга:** Здесь ИИ-ЛАБА демонстрирует подавляющее преимущество. 
    *   Министерство энергетики: **617** функций (ИИ-ЛАБА) vs. **294** (МФ).
    *   Министерство обороны: **305** функций (ИИ-ЛАБА) vs. **81** (МФ).
    *   Министерство экологии: **598** функций (ИИ-ЛАБА) vs. **380** (МФ).
    *   По большинству других министерств ИИ-ЛАБА также находит большее или сопоставимое количество функций.

**Вывод:** В рамках своей задачи ИИ-ЛАБА не просто не уступает, а **значительно превосходит** ручной метод по полноте извлеченных данных. Метод МФ оказался поверхностным, упустив большое количество функций даже в рамках тех ведомств, которые анализировались.

### 3.2. Точность и качество данных

(Выводы из предыдущей версии отчета остаются актуальными)

Анализ "сырых" данных показывает:
*   **Текст функций:** Качество текста сопоставимо. У ИИ-ЛАБА он нормализован (приведен к нижнему регистру), что является плюсом.
*   **Именование госорганов:** ИИ-ЛАБА требует постобработки для нормализации названий. В МФ названия более унифицированы.
*   **Структура метаданных:** ИИ-ЛАБА предоставляет богатую, иерархическую структуру сфер, готовую к анализу. В МФ эта классификация неструктурирована и бесполезна.

**Вывод:** ИИ-ЛАБА производит более качественные и структурированные данные, требуя лишь доработки в части нормализации названий.

### 3.3. Согласованность классификации

(Выводы из предыдущей версии отчета остаются актуальными)

Проблема расхождений в классификации типов функций (более 65% случаев) остается, но теперь ясно, что это общая методологическая проблема, а не недостаток одного из подходов. Систематические ошибки ИИ-ЛАБА потенциально легче исправить, чем хаотичные расхождения при ручном вводе.

## 4. Преимущества и недостатки каждого подхода (Скорректированная оценка)

### ИИ-ЛАБА (Автоматизированный)

*   **Преимущества:**
    *   **Высокая эффективность:** Отлично справился с поставленной задачей.
    *   **Глубина и полнота:** Извлекает максимум информации из документов.
    *   **Скорость и масштабируемость:** Легко расширяется на новые источники.
    *   **Структурированность:** Создает качественные, готовые к анализу данные.
*   **Недостатки:**
    *   **Требует постобработки:** Необходима нормализация извлеченных названий.
    *   **Непрозрачность логики:** Логика классификации ИИ требует верификации.

### МФ (Ручной)

*   **Преимущества:**
    *   **Чистые названия:** Меньше проблем с именованием сущностей.
*   **Недостатки:**
    *   **Поверхностный анализ:** Пропускает огромное количество функций.
    *   **Низкая эффективность:** Крайне трудозатратен и медленен.
    *   **Непоследовательность:** Высокий риск ошибок из-за человеческого фактора.
    *   **Плохая структуризация метаданных.**

## 5. Заключение и Рекомендации

**Автоматизированный подход (ИИ-ЛАБА) является однозначным победителем.** Он не только полностью справился с задачей анализа министерств, но и показал значительно более высокое качество в глубине и структурированности данных по сравнению с ручным методом.

**Рекомендуемые следующие шаги:**

1.  **Расширить скоуп для ИИ-ЛАБА:** Использовать список агентств и прочих ведомств из базы МФ как основу для новой задачи — найти их положения и обработать с помощью скриптов ИИ-ЛАБА.
2.  **Улучшить нормализацию:** Доработать алгоритмы очистки для автоматического сопоставления разных вариантов написания госорганов.
3.  **Создать эталон для классификации:** Разработать экспертами небольшой эталонный набор данных (100-200 функций) для дообучения и валидации модели, отвечающей за определение типов функций. Это позволит выработать единую методологию.
4.  **Полностью перейти на автоматику:** Использовать ручной труд только для экспертной проверки результатов и формирования новых задач для автоматизированной системы.
