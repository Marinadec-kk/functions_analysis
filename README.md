# Анализ государственных органов Республики Казахстан

## Описание проекта 📝

Этот проект представляет собой десктоп-приложение для анализа функций государственных органов Республики Казахстан. Приложение автоматизирует процесс сбора, обработки, классификации и анализа текстовых данных из документов, предоставляя в итоге подробные отчеты.

## Ключевые возможности ✨

- **Парсинг документов**: Автоматическое извлечение данных из `.docx` файлов.
- **Классификация функций**: Определение типов и сфер деятельности для каждой функции с использованием AI.
- **Группировка и поиск дубликатов**: Семантический поиск и группировка схожих функций.
- **Верификация дубликатов**: Использование AI для подтверждения дубликатов.
- **Генерация отчетов**: Создание подробных markdown-отчетов по результатам анализа.
- **Гибкая конфигурация**: Настройка параметров через `config.ini` и переменные окружения.
- **Пользовательский интерфейс**: Удобный GUI на Tkinter для управления процессом анализа.

## Структура проекта 🏗️

- **`main.py`**: Главный файл для запуска приложения.
- **`backend/`**: Содержит всю логику анализа.
  - **`pipeline.py`**: Оркестратор всего процесса анализа.
  - **`parsing_module.py`**: Модуль для парсинга документов.
  - **`typology_module.py`**: Модуль для классификации типов функций.
  - **`spheres_module.py`**: Модуль для классификации сфер функций.
  - **`grouping_module.py`**: Модуль для группировки функций.
  - **`duplicates_module.py`**: Модуль для верификации дубликатов.
  - **`markdown_module.py`**: Модуль для генерации отчетов.
- **`frontend/`**: Содержит графический интерфейс.
  - **`gui_app.py`**: Реализация GUI на Tkinter.
- **`config.py`**: Скрипт для управления конфигурацией.
- **`config.ini`**: Файл для пользовательской конфигурации.
- **`requirements.txt`**: Список зависимостей проекта.

## Установка 🚀

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL репозитория>
    cd <папка проекта>
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # Для Windows: venv\Scripts\activate
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

## Как запустить 🚀

Для запуска приложения выполните следующую команду в корневой директории проекта:

```bash
python main.py
```

Откроется графический интерфейс, где вы сможете настроить параметры анализа и запустить процесс.

## Конфигурация ⚙️

Вы можете настроить приложение, отредактировав файл `config.ini`. Также можно использовать переменные окружения для переопределения настроек.

Приоритет конфигурации:
1.  Переменные окружения (наивысший приоритет)
2.  Файл `config.ini`
3.  Значения по умолчанию в `config.py` (наинизший приоритет)

Пример `config.ini` можно найти в файле `config.ini.example`.

### Основные параметры для конфигурации:

- **`AI_API_BASE_URL`**: URL для API, используемого для AI-операций.
- **`AI_API_KEY`**: Ключ для доступа к AI API.
- **`DEFAULT_INPUT_DOCS_DIR`**: Папка с входными документами для анализа.
- **`DEFAULT_OUTPUT_DIR`**: Папка для сохранения результатов анализа.
