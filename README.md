# Анализ государственных органов Республики Казахстан 🇰🇿🏛️

## Описание проекта 📝

Проект посвящен анализу функций государственных органов Республики Казахстан.

## Цели проекта 🎯

Цель проекта - предоставить аналитические данные и информацию о функциях государственных органов Республики Казахстан, чтобы помочь в принятии решений и управлении государством.

## Структура проекта 🏗️

Проект состоит из следующих частей: 👇
1.  Парсинг самих функций из положений государственных органов Республики Казахстан 📑
2.  Обработка данных и составление базы данных 🗃️
3.  Разметка и классификация функций 🏷️📊
4.  Непосредственный анализ функций государственных органов Республики Казахстан 🔬
    1.  Анализ функций по составленным категориям
    2.  Сравнение функций между собой
    3.  Выделение аномалий
    4.  Выделение ключевых функций
5.  Представление результатов анализа в удобном виде 📊📈🗺️
    1.  Представление результатов анализа в виде таблицы
    2.  Представление результатов анализа в виде графиков
    3.  Представление результатов анализа в виде карты
