### **Раздел 3: Хронология Проблем и Ошибок**

Предыдущий ИИ (Gemini) столкнулся с рядом проблем и совершил множество ошибок. Их понимание критически важно для успеха:

1.  **`UnicodeEncodeError` в консоли Windows:** Базовая проблема. `run_shell_command` не может печатать кириллицу в консоль.
    *   **Решение:** Всегда сохранять результаты, содержащие кириллицу (данные, отчеты), в текстовый файл с кодировкой `utf-8`, а затем читать этот файл. **Никогда не пытаться печатать (`print`) кириллицу напрямую.**

2.  **Отсутствие библиотек Python:** В среде пользователя не были установлены `pandas`, `thefuzz`, `tqdm`.
    *   **Решение:** Были установлены через `pip`.

3.  **Несколько сред Python:** `pip` и `python` указывали на разные версии Python, из-за чего установленные библиотеки не были видны.
    *   **Решение:** Использовать `python -m pip install ...` для гарантированной установки в нужную среду. Также была решена проблема отсутствия `pip` в одной из сред через `python -m ensurepip`.

4.  **`InvalidIndexError` в Pandas:** При попытке создать итоговый DataFrame скрипт слияния падал из-за дублирующихся названий служебных столбцов.
    *   **Решение:** Переименовать служебный столбец в одной из таблиц перед объединением.

5.  **Систематические синтаксические ошибки:** Предыдущий ИИ **многократно** совершал одни и те же синтаксические ошибки при перезаписи скриптов, что и стало причиной провала и необходимости этой инструкции.
